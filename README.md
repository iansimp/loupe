# Loupe

Live: https://iansimp.github.io/loupe/

Working name. Listing photo watchdog for Etsy makers.

This public page is the Sky v2 clickable demo with sample shops. Sign in as June and walk through Home, Watching, matches, and the packet. Pasting a live Etsy URL and running Lens checks are not on this host. Those stay on the private build.

Source of this site is the Next.js app in `iansimp/cursor` under `solopreneur/loupe/web`, exported and pushed here. Pages should stay **Deploy from a branch** (`main`, `/`). Do not push a GitHub Actions workflow.

Not affiliated with Etsy. Not a live signup.
